# AI Crime Scene Investigation System

An AI-powered crime investigation prototype built with FastAPI, React, OpenCV and YOLOv8.

## Features

- Crime case management
- Evidence image upload
- YOLOv8 object detection
- Annotated evidence images
- Investigation timeline
- Chain-of-custody tracking
- Report generation
- RAG-based evidence search

## Technology Stack

- Python and FastAPI
- React.js
- YOLOv8
- OpenCV
- Docker
- Microsoft Azure Container Apps

## Live Demo

https://csi-investigation.proudcoast-4e665340.uaenorth.azurecontainerapps.io
